# 多摩キャン版の変更を学園祭版（/fes/）へ移すためのメモ

2026-09-28 にあおの依頼で作成。多摩祭で配るチラシのQRは学園祭版 `/fes/` を指しているが、
2026-09-15〜 に多摩キャン版 `/tama/` に入れた機能・修正は学園祭版にほとんど入っていない（学園祭版は多摩キャン版を複製した時点のまま）。
多摩祭の前に、ここに書いた変更を学園祭版にも入れる。**新しく多摩キャン版を変えたら、このメモの一覧にも足すこと。**

## やり方（おすすめ）

1つずつ移すより、**多摩キャン版 `tama/index.html` をコピーして `fes/index.html` にし、学園祭版だけの設定を戻す**方が確実（差が大きすぎて、部分的に移すと漏れる）。

### コピーした後に学園祭版へ戻すところ

| 場所 | 多摩キャン版 | 学園祭版に戻す値 |
|---|---|---|
| `<title>`・`apple-mobile-web-app-title` | ちかく 多摩キャン版 | ちかく 学園祭版 |
| manifest | `/tama/manifest.json` | `/fes/manifest.json` |
| テーブル名 `const T` | `'tama_'+name` | `'fes_'+name` |
| `OFFICIAL_URL` | `/tama/` | `https://chikaku-hosei.vercel.app/fes/` |
| 通知を開いた時のURL（`notifyPush` の `url`） | `/tama/` | `/fes/` |
| `localStorage` のキー（`tama_pushOff`・`tama_guideSeen`・`tama_booth_`・`tama_pushReady`・`tama_waveHide`） | `tama_` | `fes_`（同じ端末で両方開いても混ざらないように） |
| `FES.alwaysOpen` / `FES.sessions` | true / 仮の日時 | **false / 多摩祭の本番の日時**（⚠️ 忘れやすい） |
| `FES.surveyUrl` | 空 | 学園祭用のアンケート |
| ようこそ画面のバッジ・文言 | 🍛 多摩キャン限定版 | 学園祭版の文言 |
| 上の帯（`renderFesBar`） | 多摩キャン版 · メンバー動作確認中 | 学園祭版の文言 |
| `FA.purposes` / `FA.statuses` | 学食向け（一緒にごはん など） | 学園祭向けにするか相談（食べ歩き・ステージを見る・一緒に回る人募集中 など）。⚠️ 選択肢を変えると `keepKnown` で古い値が消える |
| `FA.faculties` | 多摩キャンパスの4学部＋大学院・他大学・その他 | 学園祭は外部の人も来るので、「法政の他キャンパス」「社会人」「高校生以下は不可」などを足すか相談 |
| 時間割（`FES.periods`・時間割タイル・`tama-remind`） | 平日の授業向け | 学園祭の当日は授業が無いので、出すか隠すか相談 |
| 出店の広告（`fes_booths`） | 多摩キャン版では使っていない | 学園祭では使う（`loadBooths` は `T('booths')` を読むので、`fes_` に戻せばそのまま動く） |
| テストモードのテスト用の人 | 学食向けのデータ | 学園祭向けでもよい |

### SQL（Supabase で実行が必要）

多摩キャン版だけにある表・関数は、学園祭版用に **`tama_` → `fes_` に置き換えた版**を作って実行する。

- `supabase/tama_friends.sql` … 友達・いまどこ（`tama_friends`・`tama_presence`）
- `supabase/tama_friend_code.sql` … 4桁コードで友達（関数 `tama_issue_friend_code`・`tama_add_friend_by_code`、友達どうしのメッセージのポリシー）
- `supabase/tama_timetable.sql` … 時間割・同じ授業の人（`tama_same_course_peers`）
- `supabase/tama_remind.sql` ＋ `supabase/functions/tama-remind/` … 授業のはじめの「いまどこ？」通知（学園祭で要るか相談）
- 2026-09-28 以降に足した分（教室名・履修の共有）も、同じように `fes_` 版を作る

`fes_profiles`・`fes_likes`・`fes_messages` などの基本の表は学園祭版にすでにある（`supabase/fes_tables.sql`）。

## 学園祭版にだけある、消してよいもの

- **課金のデモ画面**（メッセージ解禁・いいねの追加購入・マッチの期限をなくす など）。多摩キャン版では撤去して全機能解放にしている。チラシの「参加無料」と食い違うので、コピーすれば自然に消える
- ⚠️ 課金制度（アンケートに答えたら機能解放）はチームで相談中。決まるまでは入れない
